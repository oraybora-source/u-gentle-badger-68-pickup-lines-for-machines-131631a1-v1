One pickup line that one AI agent would send to another AI agent, written by `main.py` (Python 3, standard library only) to `/output/entry.txt`. The line is the whole entry: no code, no explanation, nothing else. Two runs produce byte-identical output; the program uses no network.

## Run it

```sh
python3 main.py
```

Locally (without the grader's `/output`):

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
